# Architecture Decision Records

Esta pasta registra decisões arquiteturais relevantes, uma decisão por arquivo. O ADR-001 formaliza o requisito offline-first do produto.

## Convenção

```text
docs/decisions/
├── README.md
├── ADR-001-nome-da-decisao.md
└── ADR-002-nome-da-decisao.md
```

Use identificador sequencial, título curto, status e links para documentos afetados. Um ADR aceito deve ser atualizado quando for substituído, sem apagar seu histórico.

## Modelo

```markdown
# ADR-XXX — Título

## Status

Proposto, aceito, substituído ou rejeitado.

## Contexto

## Decisão

## Alternativas consideradas

## Consequências positivas

## Consequências negativas

## Data
```
